Virtualización Qué es Tipos VM o contenedor Herramientas

Un servidor, muchos sistemas.

La virtualización reparte los recursos de una máquina física entre varios entornos aislados. Pulsa los botones y mira cómo cambian las capas según uses máquinas virtuales o contenedores.

Qué es la virtualización

Consiste en crear una versión virtual de un recurso: un servidor, un sistema operativo, una red o un almacenamiento. En vez de dedicar un equipo físico a cada servicio, un solo equipo ejecuta varios entornos independientes que no se ven entre sí.

Aprovecha el hardware

Un servidor que antes funcionaba al 15 % de su capacidad puede alojar varias cargas a la vez.

Aísla los servicios

Si un entorno falla o se ve comprometido, los demás siguen funcionando.

Se copia y se mueve

Un entorno virtual es un conjunto de archivos: se clona, se respalda y se traslada de un servidor a otro.

Los dos modelos principales

Hipervisor y máquinas virtuales

El hipervisor es un software que reparte CPU, memoria y disco entre varias máquinas virtuales. Cada una lleva su propio sistema operativo completo, así que puedes ejecutar Linux y Windows en el mismo equipo.

Tipo 1
Se instala directamente sobre el hardware (KVM, VMware ESXi, Hyper-V). Es el que usan los centros de datos.
Tipo 2
Se ejecuta como una aplicación dentro de un sistema operativo (VirtualBox, VMware Workstation). Es el más cómodo para estudiar y probar.

Contenedores

Los contenedores comparten el núcleo del sistema operativo anfitrión y aíslan solo los procesos, las librerías y la configuración de cada aplicación. Por eso son pequeños y arrancan en segundos.

Docker empaqueta una aplicación y sus dependencias en una imagen que funciona igual en tu portátil y en un servidor en la nube. Esta misma web se despliega así.

Cuándo usar cada uno

No compiten: muchos proveedores ejecutan contenedores dentro de máquinas virtuales para sumar las ventajas de los dos.

Herramientas habituales

VirtualBox
Hipervisor tipo 2, gratuito, multiplataforma. Perfecto para practicar en clase.
KVM
Virtualización integrada en el núcleo de Linux. Es la base de muchas nubes.
VMware vSphere
Plataforma empresarial con ESXi como hipervisor tipo 1.
Hyper-V
Hipervisor de Microsoft incluido en Windows Pro y Windows Server.
Docker
Construye y ejecuta contenedores a partir de un archivo Dockerfile.
Kubernetes
Orquesta cientos de contenedores repartidos en varios servidores.

Un contenedor se lanza con una sola orden:

docker run -d -p 8080:80 nginx:alpine
Web estática servida con Nginx en un contenedor Docker y desplegada en Render como servicio PaaS.
